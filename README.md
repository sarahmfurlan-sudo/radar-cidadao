# Radar Cidadão

> **Radar Cidadão:** cidadãos registram problemas da cidade, sensores confirmam os riscos e a população recebe alertas para se proteger de alagamentos.

Radar Cidadão é um app de zeladoria urbana colaborativa. O MVP é focado em **chuva e alagamento**.

Projeto da Global Solution 2026.2 da FIAP, tema **CitizenTech**.

## Objetivos de Desenvolvimento Sustentável (ODS)

- **ODS 11 – Cidades e Comunidades Sustentáveis** (principal)
- **ODS 13 – Ação Contra a Mudança Global do Clima** (secundário)
