# Computação Quântica

Estudo de um gargalo do Radar Cidadão quando o número de cidadãos e relatos cresce: o despacho das equipes de resposta durante chuvas fortes. O relatório mostra a capacidade quântica que poderia resolver o problema (otimização), um roadmap com critérios para avançar e a análise de ética, LGPD e ODS. A disciplina não exige código.
