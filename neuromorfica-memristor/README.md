# Cluster Computing, Computação Neuromórfica e Supercomputadores

Simulação de um memristor no Falstad como "memória de alagamento": o circuito guarda o registro de que houve alagamento no ponto mesmo depois que a água baixa. O relatório compara os ensaios no Falstad (condições A, B, C e D) com a previsão numérica feita em Python.

Arquivos:
- `Relatorio_Memristor_CitizenTech.pdf`: relatório com o circuito, os ensaios e o link do circuito no Falstad.
- `sim.py`: previsão numérica com as mesmas equações e parâmetros do memristor do Falstad.
